# Pieza Exacta

Пошук автозапчастин на Next.js (React) із серверним чатом на GPT-6 Luna та вебпошуком на Avto.pro.

## Запуск

1. Встановіть Node.js 20+ та виконайте `npm install`.
2. Створіть `.env.local` на основі `.env.example` і впишіть `OPENAI_API_KEY`.
3. Запустіть `npm run dev` та відкрийте `http://localhost:3000`.

Коли підбір не вдається підтвердити, чат пропонує тестову форму ручної перевірки. Після введення номера і згоди форма показує підтвердження прийняття запиту; надсилання даних експерту в прототипі не підключено.

Ключ створюється у [налаштуваннях OpenAI Platform](https://platform.openai.com/api-keys). Його потрібно зберігати тільки на сервері. Для API потрібні доступ до моделі `gpt-6-luna`, активний білінг і оплата викликів моделі та вебпошуку.

## Як працює пошук

`app/api/chat/route.js` виконує пошук через Responses API та формує структуровану інформаційну відповідь. Посилання в картках проходять перевірку: вони повинні бути серед URL, повернутих вебпошуком, і вести на `avtopro.ua` для української та англійської мов або `avtopro.es` для іспанської. Інші сайти можуть бути джерелами технічної інформації, але не посиланнями для покупки. Якщо релевантного оголошення на потрібному домені немає, картка не створюється.

Постійні правила помічника зберігаються в `lib/partsAssistantPolicy.js` і передаються як високопріоритетні `instructions` під час **кожного** виклику моделі. Вони обмежують тематику запчастинами, описують перевірку VIN і доказів сумісності, вимоги до OEM та аналогів, уточнювальні питання й поведінку при невизначеності. Очевидно сторонні запити та VIN з некоректним форматом відхиляються на сервері без виклику моделі. Зараз підключено лише пошук по сторінках Avto.pro: для достовірного декодування номерного знака та підтвердження комплектації за VIN потрібне окреме авторизоване джерело даних. Тому вебзбіги не позначаються як остаточно підтверджена сумісність.

Окремий запит із номером OEM або артикулом (наприклад, «знайди 3D4839015K») одразу запускає пошук за кодом без запиту VIN. VIN, іспанський номер реєстрації або характеристики авто потрібні для підбору запчастини під конкретний автомобіль.

У режимі прототипу асистент може показувати ймовірну модель авто та попередні варіанти деталей за неповними даними. Такі збіги позначаються як можливі або непідтверджені; точна сумісність не гарантується.

Мова зберігається в `localStorage`. Сайт має інформаційний характер: показує номери OEM, аналоги, пояснення сумісності та посилання на джерела. Ціни, кошик і оформлення замовлень відсутні.

## Обмеження

- Вебпошук не гарантує повноти технічної інформації.
- Збіг OEM або аналогового номера сам по собі не доводить сумісність із конкретним VIN.
- Для публічного доступу варто додати авторизацію або ліміти запитів, щоб контролювати витрати API.
- Без `OPENAI_API_KEY` інтерфейс відкриється, але серверний чат поверне повідомлення про відсутній ключ.

## Якщо `npm install` завершується з `ENOTCACHED`

Це означає, що npm працює в офлайн-режимі та не має потрібних пакетів у кеші. Запустіть у папці проєкту `npm install --offline=false`. Перевірити режим можна командою `npm config get offline`. Якщо значення `true` встановлено у вашій конфігурації npm, вимкніть його командою `npm config set offline false`.
